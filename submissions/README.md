# Representative Source-Only Archives

These archives preserve representative agent source and deck configurations:

- `submission 11.5-source-only.zip`: Hydreigon ex / Mega Gengar ex.
- `submission NsZoroark 1.5-source-only.zip`: N's Zoroark ex.
- `submission Palaking 1.25-source-only.zip`: earlier Palafin ex strategy.
- `submission palfingon 1.3-source-only.zip`: later Palafin ex strategy.

They contain `agent.py`, `main.py`, `deck.csv`, and the original policy helpers.
The Palfingon archive has had `EN_Card_Data.csv`, `cabt_cards.json` and
`cabt_attacks.json` removed. The other three selected archives already contained
source/configuration only and have been labeled consistently.

These are not complete, ready-to-submit replacements for the private competition
packages. Metadata-dependent scoring requires authorized local dependencies.
Obtain organizer assets separately, validate locally, and use the existing
submission builders when preparing a competition submission. Those builders may
include local card data, so their outputs must not be published automatically.

The public archives do not update the historical version labels or recorded
experiment results. No gameplay policy was changed for this publication.
